# 용어집 (klarbase-ko)

원작 Klarbase 의 게임 용어를 한국어판에서 어떻게 옮겼는지 정리한 표입니다. 화면 문구와 사전(`client/public/ko/dict-*.js`)은 이 표를 따릅니다.

| 원문 | 한국어 | 메모 |
| --- | --- | --- |
| Klarbase | Klarbase | 게임 이름은 그대로 둡니다 |
| isle | 섬 | 한 판의 퍼즐 단위 |
| chapter | 챕터 | 다섯 테마 + 확장 챕터 |
| Twist | 변형 | 챕터마다 있는 어려운 부가 섬 |
| Confluence | 합류 | 두 챕터의 별자리를 모두 밝혀야 열리는 섬 |
| Daily Isle | 데일리 섬 | 날마다 같은 섬 |
| Pip | 핍 | 주인공 새싹 정령. 이름은 그대로 둡니다 |
| par | 기준 | 기준 이동 수. 맞추면 ★★★ |
| star (goal) | 별 (목표) | 빛나는 별에 닿으면 클리어 |
| moves | 이동 | HUD 이동 수 |
| keys | 열쇠 | 문 하나당 열쇠 하나 |
| seeds | 씨앗 | 선택 수집물 |
| crate | 상자 | 밀 수 있는 물건 |
| plate | 압판 | 눌리면 게이트가 열림 |
| gate | 게이트 | 모든 압판이 눌려 있을 때 열림 |
| lever | 레버 | Space로 다리를 뒤집음 |
| bridge | 다리 | 레버로 뒤집히는 다리 |
| sunk bridge | 잠긴 다리 | 상자가 올라가면 막힌 칸이 됨 |
| arch | 아치 | 짝 아치로 이동 |
| door | 문 | 열쇠로 열림 |
| ramp | 경사로 | 경사 방향으로만 오르내림 |
| ice | 얼음 | 멈출 때까지 미끄러짐 |
| water | 물 | 상자가 가라앉아 디딤돌이 됨 |
| pan (Sky Scales) | 접시 (하늘 저울) | 덩굴에 매달린 두 접시 |
| weight | 무게 | 나·상자 1, 돌 더미를 든 나 2, 부표 −1 |
| balloon | 풍선 | 무게 0, 활공 |
| stones | 돌 (돌더미) | 들면 무게 2 |
| buoy | 부표 | 무게 −1, 한 층 떠오름 |
| vent | 바람구멍 | 가벼운 것을 한 칸씩 밀어냄 |
| boulder | 바위 | 제 길을 구르는 장애물 |
| thorn sweeper | 가시 청소부 | 한 박자씩 도는 장애물 |
| beat | 박자 | 한 수에 한 박자 |
| bonk | 쿵 | 장애물에 부딪힌 것. 그 수는 세지 않음 |
| hint (Tip) | 팁 | H 키 |
| solution | 해법 | 해법기가 계산한 최단 경로 (로그인 필요 원문, 이 빌드에서는 잠김) |
| difficulty tiers | 산들바람 · 쉬움 · 까다로움 · 어려움 · 가혹함 · 신화 | Breeze · Easy · Tricky · Hard · Fiendish · Mythic |
| solver audit | 해법기 검사 | 자동 난이도 추정 |
| isle builder | 섬 만들기 | Create 화면 |
| map | 맵 | 여러 섬(storey)을 관문 아치로 연결 |
| gateway arch | 관문 아치 | 맵에서 섬을 잇는 아치 |
| constellation | 별자리 | 챕터별로 밝히는 별 묶음 |
| sky | 하늘 | 내가 밝힌 별 현황 |
| community isle | 커뮤니티 섬 | 저장소에 병합된 사용자 섬 |
| remix | 리믹스 | 원작 섬을 바탕으로 만든 섬 |
